# Артель — площадка частных мастеров с личной проверкой

**Живой сайт:** [artel-masters.vercel.app](https://artel-masters.vercel.app)

Next.js 16 (App Router) + TypeScript + React Three Fiber. Главная — тёмная комната, в которой по кругу висят девять фотокарточек услуг: приглушённые, набирающие цвет под курсором и ведущие каждая на свою страницу. Ремонт, репетиторы и съёмка — девять услуг, у каждой свой адрес.

**Концепт-проект.** Вымышленная площадка, придуманная для портфолио: мастера, цены и контакты не настоящие, форма ничего не отправляет.

## Что внутри

- **WebGL-кольцо на R3F без импортированных моделей** — карточка это плоскость с текстурой обложки, обесцвечивание и скруглённые углы нарисованы собственным шейдером, а не CSS-фильтром.
- **Слова живут в DOM** — подписи это настоящие ссылки, каждый кадр проецируемые на позицию своей карточки: работает Tab, работает скринридер. Без WebGL и без JS остаются девять обычных ссылок с картинками — та же версия, что видит поисковик.
- **Честный прелоадер** — процент считается от готовности шрифтов и реально загруженных текстур (`THREE.LoadingManager`), а не от таймера. После него карточки вылетают в кольцо стаггером.
- **Переход между страницами** — штора цвета бумаги со знаком раздела по центру, побуквенная анимация навигации, плавный скролл. Всё выключается при `prefers-reduced-motion`.
- **Два вида каталога** — «полотном» (редакционный ритм из шести слотов) и «списком»; блоки переезжают анимацией через GSAP Flip, выбор запоминается.
- **Пустое состояние как аргумент** — услуга без мастеров показывает, сколько мест открыто, вместо того чтобы наполниться кем попало.
- **Статический экспорт** — `output: "export"`, 11 статических страниц, никакого сервера и никаких внешних API.

## Запуск

```bash
npm install
npm run dev
```

Сборка статики в `out/`:

```bash
npm run build
```

Логотип и фавикон собраны из глифов Oranienbaum и лежат в репозитории кривыми — гарнитура в рантайме не грузится:

```bash
node scripts/build-wordmark.mjs
```

## Стек

Next.js 16, React 19, TypeScript, Tailwind v4 (токены) + собственный CSS, three.js / @react-three/fiber, GSAP (ScrollTrigger, Flip), Lenis, Golos Text через `next/font` (самохостинг, без запросов к Google). Фотографии — Pexels, скачаны локально.
